## How the Dashboard Works

```
GitHub Actions Workflow (surveillance-dashboard.yml)
    ↓ Triggers: Daily 6 AM UTC + Push to main + Manual dispatch
    ├─ Fetch surveillance data from CDC, NASA POWER, iNaturalist
    ├─ Execute 6 Jupyter notebooks (with nbconvert --execute)
    │  ├─ 01_west_nile_virus_surveillance → 01_...html
    │  ├─ 02_tick_disease_surveillance → 02_...html
    │  ├─ 04_climate_disease_correlation → 04_...html
    │  ├─ 05_climate_change_impact_analysis → 05_...html
    │  ├─ 06_current_season_monitoring → 06_...html (+ regional_summary.json)
    │  └─ 07_regional_tracking → 07_...html
    ├─ Generate dashboard/index.html (scripts/generate_dashboard.py)
    ├─ Copy static assets (CSS, images)
    └─ Deploy _site/ to gh-pages branch → Published at mgifford.github.io/aedesproject-uif/
```

## Potential Issues to Watch

### If Homepage Doesn't Show 6 Cards
- **Check**: GitHub Actions run completed successfully
  ```bash
  gh run view [RUN_ID] --log
  ```
- **Look for**: Notebook conversion errors (usually "No module named..." or cell execution failure)
- **Solution**: Check if API fetch failed (CDC/NASA down) — system should use synthetic fallback data

### If A Specific Notebook Doesn't Appear
- **Check**: Notebook converted successfully
  ```bash
  gh run view [RUN_ID] --log | grep -A5 "Converting.*notebook.ipynb"
  ```
- **Common causes**:
  - Cell execution timeout (300s default)
  - Missing data file causing KeyError (check synthetic fallback in notebook)
  - Plotly visualization error (check for deprecated property names)
- **Solution**: Run locally first
  ```bash
  jupyter nbconvert --to html --execute --ExecutePreprocessor.timeout=300 \
    notebooks/XX_notebook.ipynb
  ```

### If Regional Data Not Updating
- **Check**: Weekly ingestion workflow ran Friday 5 PM UTC
  ```bash
  gh run list --workflow weekly-data-ingestion.yml
  ```
- **Solution**: Manually trigger
  ```bash
  gh workflow run weekly-data-ingestion.yml --field week=20 --field wnv=2 --field lyme=3
  ```

### If Pages Load But Visualizations Are Blank
- **Check**: Notebook cell outputs preserved (Plotly HTML embedding)
- **Solution**: 
  - nbconvert may have stripped outputs — check CI log
  - If issue persists, may need to re-run notebook with `jupyter nbconvert --execute --embed-images`
